Tripo 用的是 Ory Kratos，不是 access/refresh 双 token： ory_kratos_session（30 天，不可续，只能重新登录）≈ 长期凭证； ES256 JWT（15 分钟，可无限续签）≈ access token。 所以 JWT 部分全自动，只有 session 到期前需要你打开浏览器点一次「捕获」。

存储策略
项目说明
数据库存什么s3_bucket + s3_key + 元数据。永久有效，图片/模型字节一律不落盘
签名 URLCloudFront 预签名，约 1~24 小时过期；随用随取，用完即弃
换签名方式/v1/db/artifacts/fresh-url?kind=&id= —— 调 get_image_asset / project/detail，服务端每次都会重新签名（实测同一产物两次取到的 URL 不同）
下载不落盘加 &download=1 返回 302 直跳官方 CDN，字节从 Tripo 直出，不经过本机
本地压力≈ 0
三个数据源 本地 DB = 本工具经手的产物（含签名状态）；
云端实时 = 账号全部资产（含官网 UI 生成的、预置模型），受 10/账号 配额约束；
合并 = 两者去重合并，云端项标注是否已入库本地。
